会議ライブ翻訳 停止中 / Stopped

不具合のときは、下の内容をコピーしてClaudeとのチャットに貼り付けてください。原因を調べるのに使います（会議の内容は入りません）。

「▶ 開始」を一度押すだけで、会議が終わるまで聞き取りと翻訳を続けます。
途中で音声認識が切れても自動で再開します。iPad・スマホは充電ケーブルにつなぎ、話す人の近くに置いてください。
表示例 / EXAMPLE
Let's start today's meeting. First, about the night-shift handover.
それでは今日の会議を始めます。まず夜勤の申し送りについてです。
Now speaking / 話している内容
