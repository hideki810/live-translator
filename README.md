# 会議ライブ翻訳（日本語 → 英語ほか）

日本語の会議の音声を聞き取り、英語などに翻訳して表示し続けるWebアプリです。
「▶ 開始」を一度押せば、「■ 停止」を押すまで動き続けます。インストールは不要で、iPad・iPhone・Androidのブラウザで使えます。

## 主な機能
- **途切れない**：音声認識が止まっても自動で再開します（無音・通信の乱れ・時間切れのとき）。
- **話している途中から訳す**：オレンジ色の行に、話している途中の内容を約1秒ごとに仮の訳で表示します。
- **一文ずつ確定**：約1.8秒の無音で一文として確定し、上の履歴に「英語（大）＋日本語（小）」で残します。
- **画面スリープ防止**：対応しているブラウザでは、翻訳中に画面が消えないようにします。
- 翻訳先の言語：英語・ベトナム語・インドネシア語・タガログ語・ミャンマー語・ネパール語・中国語
- 文字サイズの変更（A− / A＋）、日本語表示のオン・オフ、議事録の保存（.txt）

## 公開のしかた（初回だけ・無料）
マイクを使うため、**https のURL** で開く必要があります。いちばん簡単なのはNetlify Dropです。
1. パソコンで https://app.netlify.com/drop を開きます（無料のアカウント登録が必要です）。
2. `live-translator` フォルダをそのままドラッグ＆ドロップします。
3. 表示された `https://○○○.netlify.app` を、iPadのSafariで開きます。
4. Safariの共有ボタン →「ホーム画面に追加」で、アプリのように使えます。

GitHub Pagesでも公開できます（`index.html` を置くだけ）。

## 会議で使うときのコツ
- **iPad・iPhone は Safari**、**Android は Chrome** で開いてください。
- 初回は「マイク」と「音声認識」の許可を求められるので、「許可」を押してください。
- iPhone/iPad：設定 →「画面表示と明るさ」→「自動ロック」を「なし」にしておくと安心です。
- 充電ケーブルにつなぎ、話す人の近くに置いてください。小さな外付けマイクがあると精度が上がります。
- 翻訳中に別のアプリへ切り替えると聞き取りが止まります。画面に戻ると自動で再開します。
- インターネット接続が必要です（音声認識と翻訳はオンラインで行います）。

## Android（Google Chrome）で使うとき
- 必ず **Google Chrome** で開いてください。Samsung Internet などのブラウザは音声認識に対応していません。
- Androidでは、文ごとに聞き取りを区切ってすぐ再開する方式で動きます。Android版Chromeの連続モードでは、同じ文が何度も届く不具合があるためです。
- 機種によっては、再開のたびに「ポン」という短い音が鳴ります。気になる場合は、音量ボタンでメディアの音量を下げてください。
- ホーム画面に置くには、Chromeのメニュー（⋮）→「ホーム画面に追加」を選びます。
- 電池の最適化で止まらないよう、充電しながら画面をつけたまま使ってください。

## 精度を上げるには
### 高精度モード（Claude AI）
「設定」から「高精度モード」を選び、AnthropicのAPIキーを入れると使えます。
- 直前の4つの発言の流れを参考にして訳すので、途中で切れた文や「それ」「あれ」も自然に訳せます。
- 音声認識の聞き間違いを、話の流れから直して訳します。
- **用語集**に「申し送り=shift handover」のように登録すると、毎回同じ訳語になります。施設名・人の名前・職場の言葉を入れておくのがおすすめです。
- APIキーは https://console.anthropic.com で作成します（有料・使った分だけ）。料金の目安は、1時間の会議でOpus 5.5が約450円、Haiku 5.5が約15円です。
- 「試しに翻訳する」ボタンで、キーが正しく使えるか確かめられます。
- キーが間違っている、残高が足りないなどのときは、自動で無料モードに切り替えて訳し続けます。
- 話している途中のオレンジ色の仮の訳は、速さを優先して無料モードで出します。確定した文は高精度モードで訳し直します。

### 聞き取りの精度を上げる（どちらのモードでも効きます）
- 端末を話す人の近く（1m以内）に置きます。大きな部屋では、スマホ用の外付けマイク（数千円のピンマイクなど）を使うと大きく改善します。
- 一度に何人も話すと聞き取れません。司会の方に「一人ずつ話す」ようにお願いしてください。
- 文の終わりで少し間をあけると、区切りが正確になります。

## 途中で止まったときのために
- 画面下の小さな文字に「再接続の回数」と「最後に聞き取ってから何秒たったか」が出ます。
- 何かを聞き取っているはずなのに20秒以上何も届かないときは、自動で聞き取りを作り直します。
- それでも止まったままのときは、その表示の数字と、使っている端末（iPad / Android など）を教えてください。

## 注意点
- 翻訳には、Googleの無料の翻訳窓口（非公式）を使っています。うまくいかないときは、別の無料サービス（MyMemory）に自動で切り替えます。
  無料のため、長時間たくさん使うと制限がかかる場合があります。
  社内で本格的に使う場合は、有料の翻訳API（DeepL・Google Cloud翻訳など）につなぎ替えることをおすすめします。
- 会議の音声は、端末の音声認識サービス（Apple・Google）に送られます。機密性の高い会議では、社内のルールを確認してください。
